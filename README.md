# Асинхронный трекер билетов БелЖД (pass.rw.by)

Автоматизированный скрипт для мониторинга в реальном времени появления свободных или сданных билетов на сайте Белорусской железной дороги ([pass.rw.by](https://pass.rw.by/)).

---

### Ключевые возможности:
1. **Асинхронные параллельные запросы:** направления «туда» и «обратно» опрашиваются одновременно в отдельных вкладках браузера через Playwright.
2. **Информативные уведомления в Telegram:** при обнаружении мест бот присылает структурированное сообщение с деталями поездов, типами вагонов и прикрепленными скриншотами расписания.
3. **Удаление баннеров cookie:** всплывающие баннеры автоматически скрываются перед созданием скриншота, не перекрывая расписание.
4. **Звуковое оповещение:** воспроизводит звуковой сигнал на ПК при обнаружении свободных мест.
5. **Модульная архитектура и безопасность:** секретные токены и персональные данные хранятся в `.env` и `config/routes.json` и защищены от случайной публикации на GitHub через `.gitignore`.

## Быстрый старт

### 1. Клонирование репозитория
```bash
git clone https://github.com/your-username/train-tracking.git
cd train-tracking
```

### 2. Создание и активация виртуального окружения (рекомендуется)
```bash
python -m venv venv

# Windows:
venv\Scripts\activate

# Linux / macOS:
source venv/bin/activate
```

### 3. Установка зависимостей и браузера Playwright
```bash
pip install -r requirements.txt
playwright install chromium
```

## Настройка

### 1. Переменные окружения (`.env`)
Скопируйте шаблон `.env.example` в `.env`:
```bash
# Windows (PowerShell / CMD):
copy .env.example .env

# Linux / macOS:
cp .env.example .env
```

Откройте `.env` и укажите данные вашего Telegram-бота:
* **`TELEGRAM_BOT_TOKEN`** — токен бота, полученный у [@BotFather](https://t.me/BotFather).
* **`TELEGRAM_CHAT_ID`** — ваш Chat ID, полученный у [@userinfobot](https://t.me/userinfobot).
* **`CHECK_INTERVAL`** — интервал проверки в секундах (по умолчанию `15`).
* **`HEADLESS`** — `True` (скрытый режим) или `False` (открывать видимое окно браузера).
* **`SEND_SCREENSHOT`** — `True` (прикреплять скриншоты) или `False`.
* **`SOUND_ALERT`** — `True` (звуковой сигнал на ПК) или `False`.

---

### 2. Настройка маршрутов (`config/routes.json`)
Маршруты настраиваются в файле `config/routes.json` (файл добавлен в `.gitignore` и не попадет в репозиторий):

Скопируйте пример:
```bash
# Windows:
copy config\routes.example.json config\routes.json

# Linux / macOS:
cp config/routes.example.json config/routes.json
```

Пример `config/routes.json`:
```json
[
  {
    "name": "ТУДА (Минск -> Брест)",
    "from": "Минск-Пассажирский",
    "to": "Брест-Центральный",
    "date": "2026-12-30",
    "train": "",
    "car_types": []
  },
  {
    "name": "ОБРАТНО (Брест -> Минск)",
    "from": "Брест-Центральный",
    "to": "Минск-Пассажирский",
    "date": "2027-01-03",
    "train": "727Б, 657Б",
    "car_types": ["Плацкарт", "Купе"]
  }
]
```

## Справочник параметров маршрута

### 1. Станции (`"from"`, `"to"`):
Указывайте названия станций точно так, как они отображаются на pass.rw.by (например: `Минск-Пассажирский`, `Пинск`, `Брест-Центральный`, `Гродно`, `Гомель`).

### 2. Фильтр поезда (`"train"`):
* `""` — Любой поезд на выбранную дату (рекомендуется).
* `"657Б"` — конкретный номер поезда (Межрегиональные линии эконом-класса со спальными вагонами).
* `"727Б"` — конкретный поезд бизнес-класса (Stadler, дизель-поезд).
* `"872Б, 860Б"` — несколько подходящих поездов через запятую.

### 3. Типы вагонов и мест (`"car_types"`):
* `[]` — Любые места (рекомендуется).
* `["Плацкарт"]` — только плацкарт.
* `["Купе"]` — только купе.
* `["Плацкарт", "Купе"]` — плацкарт или купе.
* `["Сидячий"]` — сидячие места (актуально для Штадлеров).
* `["СВ"]` (или `["Люкс"]`) — двухместные купе.
* `["Общий"]` — общие вагоны.

## Проверка и запуск

### Шаг 1. Проверка Telegram-бота:
```bash
python tests/test_telegram.py
```
> Бот отправит вам тестовое сообщение. Если возникнет ошибка, проверьте, нажали ли вы кнопку START в диалоге с ботом в Telegram.

### Шаг 2. Запуск мониторинга:
```bash
python main.py
```
*(Либо дважды кликните по файлу `run.bat` на Windows).*

Для остановки мониторинга нажмите `Ctrl + C` в окне терминала.

## Важные примечания
* **VPN:** Сайт БелЖД (`pass.rw.by`) может блокировать запросы из-за границы или через иностранные VPN-сервисы (например McAfee VPN). Для стабильной работы используйте белорусское подключение.
* **Безопасность:** Никогда не коммитьте файлы `.env` и `config/routes.json` с вашим реальным токеном бота и персональными данными.
